# BurnoutRadar

**BurnoutRadar** — веб-застосунок для моніторингу особистого стану і попередження вигорання. Ідея проста: людина щодня логує кілька метрик — настрій, енергію, сон, фізичну активність, навантаження — і отримує єдиний показник **Burnout Index**, який відображає наскільки близько вона до вигорання.

---

## Проблема

Вигорання не трапляється раптово. Воно накопичується тижнями — через недосип, перевантаження, низьку енергію, відсутність руху. Більшість людей помічають його вже постфактум. BurnoutRadar намагається зафіксувати ці сигнали раніше.

---

## Як це працює

Застосунок складається з чотирьох розділів:

**Dashboard** — головний екран. Показує поточний Burnout Index, прогрес задач на сьогодні, стан по метриках (настрій, енергія, сон, рух) і персональні денні інсайти.

**Daily Planner** — планування задач на конкретний день. Кожна задача має пріоритет і рівень складності. Застосунок враховує не просто кількість задач, а їхнє реальне навантаження.

**Mood & Energy** — щоденний чекін. Настрій (1–5), ментальна і фізична енергія, сон, вода, кроки, екранний час, коротка рефлексія.

**Analytics** — графіки за останні 7 днів: динаміка Burnout Index, навантаження, настрій і енергія. Тижневі середні і автоматичні алерти на основі реальних даних.

## Burnout Index

Це головна метрика застосунку. Число від 0 до 100, яке рахується щодня на основі двох кошиків — **ризики** і **захист**.

### Ризики — що підвищує індекс

| Фактор | Максимум | Як рахується |
|---|---|---|
| Настрій | +32 | Настрій 1/5 → +32, настрій 5/5 → 0 |
| Ментальна енергія | +20 | Чим нижча енергія — тим вищий ризик |
| Сон | +32 | Кожна година нижче 8h → +4 бали |
| Навантаження | +15 | 8+ годин задач на день → +15 |
| Складність задач | +15 | Середня складність 5/5 → +15 |
| Незавершені задачі | +15 | Всі задачі не виконані → +15 |
| Екранний час | +8 | Кожна година понад 6h → +1 бал |

### Захист — що знижує індекс

| Фактор | Мінімум | Як рахується |
|---|---|---|
| Фізична енергія | -10 | Висока фізична енергія → -10 |
| Рух | -6 | 7000+ кроків → -6, 3000+ → -3 |
| Гідрація | -4 | 2000ml+ → -4, 1500ml+ → -2 |

### Формула

Сирий бал може бути від -20 (ідеальний день) до +100 (максимальне навантаження без жодного захисту). Нормалізація переводить цей діапазон у зрозумілу шкалу 0–100.

    сирий_бал = сума_ризиків - сума_захисту
    індекс = (сирий_бал + 20) / 120 x 100

Рівні:

    0 – 33   →  Low       (все добре)
    34 – 66  →  Moderate  (є сигнали, варто звернути увагу)
    67 – 100 →  High      (потрібно діяти)

## Запуск локально

    git clone https://github.com/your-username/burnout-radar.git
    cd burnout-radar

    python -m venv venv
    source venv/bin/activate

    pip install -r requirements.txt
    python manage.py migrate
    python manage.py runserver

Застосунок буде доступний на http://127.0.0.1:8000
